NOTE ON PFD (property-embedding Frechet distance, manuscript values 444.3 / 428.0):
The trained property-embedding model used for this metric was not persisted to disk
in the available run artefacts, so a matched train-vs-train PFD baseline could not be
recomputed without retraining that model from scratch. Only the FP-PCA-FD baseline
above is reproduced here; the manuscript text explicitly flags PFD as lacking an
equivalent baseline and recommends one be computed in a future revision once the
embedding-model checkpoint is retained.
